# What is CHAOS?

CHAOS is a local-first development orchestration environment designed to make AI-assisted software work more structured, more persistent, and less repetitive.

At a high level, the project brings together:

- durable working context instead of one-off chat state,
- workflow and review discipline across planning, coding, testing, and documentation,
- orchestration patterns for specialized development tasks,
- a product direction that moves from strong local tooling toward more cohesive end-to-end orchestration.

## What CHAOS is developing into

The long-term direction is a product that helps teams and solo builders:

1. keep context alive across sessions,
2. coordinate work through clear operational surfaces,
3. reduce repeated setup and re-explanation,
4. maintain strong documentation and git hygiene as part of normal execution.

This showcase repo focuses on the **process story**: how the work evolves, how the history is maintained, and how changes are communicated over time.
