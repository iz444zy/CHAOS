# Architecture Overview

This public overview describes CHAOS at the system-shape level only.

## Public-safe shape

CHAOS combines:

- a local orchestration layer,
- structured developer workflows,
- persistent context handling,
- multiple interaction surfaces for working with the system,
- supporting documentation and release discipline.

## Design direction

The system is being developed toward a tighter, more cohesive local-first experience where planning, execution, context management, and operational visibility work together instead of living as disconnected tools.

This document intentionally avoids private implementation specifics. The goal is to communicate the product direction without reproducing protected internals.
